|整体院|維持＋微修正|初回の流れ、費用、電話/LINEという不安解消型LPを維持。効果の断定なし。フォームを修正。|
|カフェ|重点改善|文字だけのお品書きを、珈琲写真と分類リンクから入る見開き型に再構成。店の営業時間・来店案内を重視し、強い予約訴求を追加しない。|
|清掃|操作修正|箇所別概算が独自の強み。概算更新で相談文が消える問題を修正し、自動概算と自由記述を分離。|
|学習塾|内容補強|教室案内の抽象性を改善。60分授業の時間配分を時系列で提示し、保護者が授業を想像できるように。合格・成績実績は創作しない。|
|技術構造|維持|26ページの静的HTML、ローカルWebP、軽いJSは小規模案件に適切。フレームワーク変更やアニメーション追加は不要。|

優先度は、応募先が短時間で判断できる情報 → 誤動作・信頼を損なう挙動 → 差別化の弱い内容 → 細部の順。共通のフォームやメニュー機構は品質維持のため共有し、業種固有の情報構造を変える。
