# 品質確認記録

確認日：2026-09-26

## 構成

8業種。LP型3作品、複数ページ型5作品。工務店Bは別案として統合。税理士・製造業は各5ページ。サンプルのHTML計24ページ、本体・画像出典を含め26ページ。

## 実施内容

- ChromiumブラウザでPC・スマホの実表示を確認。表示確認用iframeで1280・768・375・320pxの幅を確認。
- 本体とサンプル25ページ×4幅でページ幅、h1数、読み込まれた画像の状態を検査。
- 整体院の320pxで見つかった営業時間表の横はみ出しを修正。再検査でclientWidth / scrollWidthは305 / 305。
- スマホの固定ボタンの折り返し、税理士・カフェの見出し改行を修正。
- 工務店の既存写真・縦書き・間取り操作を維持。間取りと合わない写真表示を除き、イメージ写真であることを明示。
- モバイルメニューの開閉、Escapeキー、間取りのEnterキー操作を確認。
- 各フォームの入力確認表示、制作サンプルの非送信表示を確認。
- 清掃の概算計算：キッチン16,500円＋浴室17,600円＋レンジフード15,400円＝49,500円。フォームへの内容引き継ぎも確認。
- HTMLの内部リンク428件、画像・CSS・JS参照112件を検査。参照先・ページ内アンカーの欠落なし。
- 全ページのtitle、description、h1、画像altを検査。各ページh1は1つ。
- JavaScriptの構文検査を実施。
- フォーカス表示、44px以上を基本としたタップ領域、動きの軽減設定、遅延読み込みを実装。
- 工務店の橙色を調整し、白いボタン文字のコントラストを改善。
- 架空の評価、件数、受賞、顧客の声、資格番号、合格実績を除去。
- 外部フォント・外部画像リクエストに依存しない構成。画像は16点のWebP、合計約1.6MB（全作品合計）。
