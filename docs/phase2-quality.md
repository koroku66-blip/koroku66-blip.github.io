# 第2次改善版の検証

対象：improve/phase2-application-quality。初回制作の検証とは分けて記録。

## 確認結果

- HTML 26ページ・内部リンク440件・画像/CSS/JS参照114件。リンク先・アンカー欠落なし。title/description/h1/画像altの静的チェックにエラーなし。
- Chromiumのiframeを320 / 375 / 390 / 430 / 768 / 1280pxにして全26ページ（156条件）を測定。documentの横はみ出し0、読み込み失敗画像0。生データ：`phase2/responsive.json`。iframeのスクロールバーを含むため、実際のコンテンツ幅は指定値より狭い場合がある。
- JavaScriptを実行しないsandbox iframeで、清掃フォームのボタンが無効、モバイルナビが表示されることを確認。全8フォームの初期fieldset無効化とイベント登録後の解除をコードレビュー。
- 全8フォーム（工務店A/B、製造業、美容室、税理士、整体院、清掃、学習塾）を架空データで操作し、送信・保存・予約を行わない入力確認の表示を確認。
- 清掃でキッチン＋浴室＝34,100円。自由記述入力後に清掃箇所を変更しても内容保持。概算専用欄と確認画面への反映を確認。
- 美容室のスマホメニューを開き、Escapeで閉じることを確認。カフェのお品書き内リンクを確認。本体の相談メモコピーを確認。
- JS4ファイルの構文確認、git diff --checkを実施。
- ブラウザConsoleを別途確認。検査ページのonload後の監視だけでは初期化例外を検出できないため、それを根拠にしない。取得したログにサイト由来のerror/warnなし。ブラウザ拡張のmetadataエラーはサイトコードと分離。
- 別エージェントが変更前と変更後を読み取り専用でレビュー。新規の重大なコード不具合・架空実績追加・AI説明との明確な矛盾は指摘なし。概算欄の区切りと検査方法の指摘を反映。

## 見せ方の判定

- 30秒：小規模HP/LP/修正、料金入口、8業種の目次が読める。
- 3分：作品の設計ポイント、対応範囲、費用、手順、連絡先を必要な順に確認できる。
- 差別化：住宅の間取り操作、製造業の加工条件、美容室のカウンセリング、税理士の費用内訳、整体院の初回案内、喫茶店のお品書き、清掃の概算、塾の授業時間配分という用途の違いがある。共通カードの色替えだけには依存していない。
- 架空事業者・自主制作を表示。受注・売上・顧客評価・資格・成果を創作していない。
- 小規模な静的サイト制作・修正案件の応募時に、制作意図と対応範囲を説明する材料として使える品質と判断。ただし受注や案件適合を保証するものではない。

## 検証の範囲と残る改善余地

- 画面幅の検査はブラウザ上。iPhone/Android実機、Safari、全支援技術での検証ではない。
- Lighthouseのスコアや実環境のCore Web Vitalsは未計測。ローカル画像・静的HTMLを維持し、画像追加や重いライブラリの導入はしていない。読み込み性能の数値保証は行わない。
- 写真はイメージ。美容室の施術スタイル、カフェの商品を実際に撮影した素材はなく、実店舗向けに転用する際にはその店舗の素材と情報が必要。
- 問い合わせは応募元メッセージへの返信を前提とする。未確認のメール・プロフィールURLは追加していない。
- 公開サイトは未変更。mainへのマージ・デプロイをせず、安全な別版として引き渡す。
